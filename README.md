--In English--

Hi, I’m the creator of Windows Custom Menu. Here is what you need to use this custom mod. Most importantly, to get the glass-effect taskbar, you’ll need to download TranslucentTB; here is the link for the Microsoft Store: https://apps.microsoft.com/detail/9pf4kz2vn4w9?hl=ru-RU&gl=KG.
Secondly, you need to be running either Windows 10 or Windows 11.

The code for this mod is open-source and comes in the form of a .bat file. It is recommended to edit the code using Visual Studio Code only.

To make the menu functional, you can move it to the startup folder. Additionally, you need to create a folder named "MyMenu" on your desktop and place the "menu.bat" and "menu.ps1" files inside it.
